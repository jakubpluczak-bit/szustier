# CastoMarket

Sklep budowlano-remontowy (React + TypeScript + Tailwind CSS 4 + Vite).
Dane są przechowywane lokalnie w przeglądarce (IndexedDB), backend nie jest potrzebny.

## Uruchomienie

Wymagany Node.js 18 lub nowszy.

    npm install
    npm run dev       # tryb developerski, http://localhost:5173
    npm run build     # sprawdzenie typów + build produkcyjny do dist/
    npm run preview   # podgląd zbudowanego projektu

Przycisk „Resetuj bazę danych" w stopce przywraca dane początkowe.
